# To-Do Web App

A simple, responsive To-Do Web App built with HTML, CSS, and vanilla JavaScript. It helps users organize daily tasks, track their progress, and manage pending and completed activities through a clean, modern interface.

## Features

- **Add Tasks:** Create new tasks with a simple input field.
- **Mark as Complete:** Mark tasks as completed or return them to pending.
- **Edit Tasks:** Edit task titles directly on the page.
- **Delete Tasks:** Remove tasks when they are no longer needed.
- **Task Counters:** View total, completed, and pending task counts.
- **Task Filters:** Display all tasks, pending tasks, or completed tasks.
- **Date and Time:** View when each task was created.
- **Local Storage:** Automatically save tasks in the browser so they remain available after refreshing the page.
- **Empty-State Messages:** Display helpful messages when no tasks are available in the selected view.
- **Responsive Design:** Use the application on desktop and smaller screens.
- **Animated Welcome Message:** Display an introductory message with a typing effect.

## Technologies Used

- HTML5 — page structure
- CSS3 — styling, layout, and responsive design
- JavaScript (Vanilla) — task management and DOM manipulation
- Browser Local Storage — saving tasks locally

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding and managing your tasks.

No backend server or database setup is required.

## How Data Is Stored

The application uses the browser's `localStorage` to save task information. Tasks remain available after refreshing the page in the same browser profile, provided the browser data is not cleared.

**Note:** Tasks are stored locally and are not automatically synchronized across different devices or browsers.
