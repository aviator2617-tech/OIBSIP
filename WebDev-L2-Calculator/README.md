# Calculator

A simple browser-based calculator developed for the **Oasis Infobyte Web Development Internship — Level 2, Task 1**.

The project combines a clean green-themed interface with JavaScript-based arithmetic functionality.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number input
- Clear and delete buttons
- Separate expression and result displays
- Error handling for invalid calculations and division by zero
- Four-column button layout using CSS Grid
- Interactive button hover and click effects
- Rounded calculator panel with a green-and-white color scheme

## Technologies Used

- **HTML5** — Structures the calculator interface
- **CSS3** — Styles the calculator, display, and buttons
- **Vanilla JavaScript** — Handles button interactions and calculation logic

## Design

The calculator uses an Emerald Minimal-inspired design featuring green tones, a white background, rounded corners, and a centered layout. CSS Grid organizes the calculator buttons, while hover and click effects improve visual feedback.

## Project Structure

- `index.html` — Contains the calculator's HTML structure
- `style.css` — Defines the layout, colors, and button styles
- `script.js` — Handles user input and calculations

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the calculator interface to perform calculations.
