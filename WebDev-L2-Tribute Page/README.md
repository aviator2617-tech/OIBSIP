# Grace Hopper Tribute Page

## About the Project

This project is a tribute webpage dedicated to **Grace Hopper**, a pioneering computer scientist and United States Navy rear admiral who made significant contributions to computer programming and the development of programming languages.

The webpage presents her life, career, achievements, and legacy through a clean, responsive design inspired by a classic historical theme.

This project was developed as part of **Level 2 – Task 2** of the Oasis Infobyte Web Development Internship.

## Features

- **Introduction Section:** Introduces Grace Hopper with a portrait and a short         description.
- **Biography Section:** Highlights important details about her life and career.
- **Achievements Timeline:** Presents key milestones in her professional journey.
- **Inspirational Quote:** Features a quote attributed to Grace Hopper.
- **Responsive Design:** Uses CSS to adapt the layout to different screen sizes.
- **Back to Top Button:** Allows visitors to return smoothly to the top of the page.
- **Theme Design:** Uses forest green, warm ivory, sage, and antique gold for a classic appearance.
- **Dark/Light Theme Toggle:** Allows visitors to switch between dark and light themes for a more comfortable viewing experience.

## Technologies Used

- HTML5 — webpage structure and content
- CSS3 — styling, layout, and responsive design
- JavaScript — interactive Dark/Light Theme toggle and Back to Top button.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Scroll through the biography and achievements, then test the Back to Top button.

No additional installation is required.
